🚀 TIDP-SUFee 部署步驟

請輸入你的 GitHub 使用者名稱，然後依序點擊按鈕執行。

步驟 1：建立儲存庫

點擊下方按鈕開啟 GitHub 建立新儲存庫頁面（名稱已預填 TIDP-SUFee）

步驟 2：推送程式碼

在專案目錄開啟終端機，執行以下指令（請將 你的帳號 改為你的 GitHub 使用者名稱）：

git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/你的帳號/TIDP-SUFee.git
git branch -M main
git push -u origin main

步驟 3：設定 Secrets

點擊按鈕開啟 Secrets 設定頁面，新增：

  • CLOUDFLARE_API_TOKEN - Cloudflare API Token
  • CLOUDFLARE_ACCOUNT_ID - Cloudflare Account ID

步驟 4：執行部署

設定完成後，點擊按鈕開啟 Actions 並手動執行 Deploy to Cloudflare Pages
